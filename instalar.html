Instale o Portal no seu dispositivo

Tenha acesso às disciplinas, notebooks e materiais educacionais diretamente pelo computador, tablet ou celular.

Computador — Windows

Instalação pelo Microsoft Edge:

  1. Abra o Portal no Microsoft Edge.
  2. Clique no menu de três pontos (...).
  3. Selecione Aplicativos.
  4. Escolha Instalar este site como aplicativo.
  5. Confirme a instalação.

Celular — Android

Instalação pelo Google Chrome:

  1. Abra o Portal no Chrome.
  2. Toque no menu de três pontos.
  3. Selecione Instalar aplicativo ou Adicionar à tela inicial.
  4. Confirme a instalação.

iPhone e iPad

Instalação pelo Safari:

  1. Abra o Portal no Safari.
  2. Abra o menu de compartilhamento.
  3. Selecione Adicionar à Tela de Início.
  4. Confirme a operação.

Tablet — Android

Instalação pelo Google Chrome:

  1. Abra o Portal no Chrome do tablet.
  2. Toque no menu do navegador.
  3. Selecione Instalar aplicativo ou Adicionar à tela inicial.
  4. Confirme a instalação.

Acesso pelo QR Code

Aponte a câmera do celular ou tablet para acessar a página de instalação do Portal Engenharia Química.
